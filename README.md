# Movie Recommender System

A content-based movie recommender built with Python, Scikit-learn and Streamlit.

Live app: https://movie-recommender-ankur.streamlit.app/

## How it works
- Combined genres, keywords, cast, director and overview into tags
- Applied stemming and CountVectorizer to create vectors
- Used cosine similarity to find similar movies
- Posters and ratings fetched from the TMDB API

This product uses the TMDB API but is not endorsed or certified by TMDB.
